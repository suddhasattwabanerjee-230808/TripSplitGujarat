# TripSplit

A Flutter expense splitter for a three-person trip. The starter trip is a
Gujarat getaway in Ahmedabad, with shared expenses, per-person balances, and
suggested transfers that settle the group.

## Run

Install Flutter and the Android toolchain, connect an Android device or start an
emulator, then run:

```powershell
flutter pub get
flutter run
```

The iOS project is included for builds from macOS with Xcode. Expenses are saved
locally on the device.
